# vaulthalla-price-bot

`vaulthalla-price-bot` is a standalone Python service/tooling repo for object-storage pricing profiles used by Vaulthalla. It fetches official provider pricing sources, stores raw and normalized data in Postgres, publishes signed static artifacts, and serves a small API so Vaulthalla installs do not scrape vendor pages locally.

## Local setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Create a `.env` file with:

```dotenv
DATABASE_URL=postgresql+psycopg://user:password@localhost:5432/vaulthalla_price_bot
PRICE_BOT_RAW_DIR=data/raw
PRICE_BOT_PUBLIC_DIR=public/v1
PRICE_BOT_SIGNING_PRIVATE_KEY_PATH=.secrets/ed25519.key
PRICE_BOT_SIGNING_PUBLIC_KEY_PATH=.secrets/ed25519.pub
PRICE_BOT_LIVE=0
```

## Core commands

```bash
price-bot db init
price-bot sources list
price-bot refresh --fixture-dir tests/fixtures/providers
price-bot normalize
price-bot publish --out public/v1
price-bot validate public/v1/manifest.json
price-bot estimate --profile tests/fixtures/profiles/r2-standard.json --usage tests/fixtures/usage/r2-standard-free-tier.json
price-bot serve --host 127.0.0.1 --port 8080
```

Live provider fetching is disabled unless `--live` is passed or `PRICE_BOT_LIVE=1`.

## Deployment

The repo includes a bash installer for Debian/Ubuntu hosts. It creates or reuses the
repo-local `.venv`, installs the package with gunicorn, and can wire systemd,
nginx, and certbot.

```bash
make install ARGS="-y --domain prices.example.com --port 8080"
```

Without `-y`, the installer prompts for which components to install. Component
flags install only the selected pieces:

```bash
make install ARGS="--service --port 8080"
make install ARGS="--nginx --certbot --domain prices.example.com --port 8080"
```

The generated service runs gunicorn on `127.0.0.1:<port>` as the checkout owner.
The nginx template proxies the public domain to that local port. If certbot is
selected, the installer checks for an existing certificate, attempts renewal
first, then runs certbot's nginx installer with keep-until-expiring behavior.

Remove deployed components with:

```bash
make uninstall ARGS="-y --domain prices.example.com"
```

`make uninstall` without `-y` prompts before removing the service, nginx site,
and certificate. The uninstaller does not remove `.env`, `.venv`, `.secrets`,
`data/`, or `public/`.

## Vaulthalla consumption model

Vaulthalla should fetch `public/v1/manifest.json`, verify `manifest.json.sig` with the exported Ed25519 public key, then fetch only the profile JSON files it needs. Each profile is deterministic JSON with decimal strings for rates and includes confidence, provenance, known exclusions, and a content hash.

The static artifact set is intended to be published periodically by this tool, not generated by Vaulthalla installs.

## Provider coverage

| Provider | Source preference | Prototype coverage |
| --- | --- | --- |
| AWS S3 | Official AWS Price List Bulk/Query API | Fixture-driven parser with official API source path documented |
| Cloudflare R2 | Official docs markdown, HTML fallback | Standard and Infrequent Access |
| Wasabi | Official pricing HTML | Pay-as-you-go storage-only |
| Backblaze B2 | Official pricing HTML | Pay-as-you-go and Overdrive |
| DigitalOcean Spaces | Official docs markdown, HTML fallback | Standard Spaces and Cold Storage |
| Storj | Official docs pricing pages | Current tiers and legacy profile |
| MinIO | Official product/pricing pages | Manual-required self-host profile |
| Ceph | Official RGW docs | Manual-required self-host profile |
| Other | Operator supplied | Manual-required profile |

## Accuracy caveats

Profiles exclude taxes, enterprise discounts, promotional credits, account-wide usage outside Vaulthalla, private contracts, destination-specific egress exceptions, and invoice rounding that cannot be derived from Vaulthalla metrics.

Confidence is lower for HTML-only sources and manual profiles. Self-host providers require operator-supplied infrastructure pricing.
